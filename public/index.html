    What the agent can and cannot do

    • Can check the wallet balance and your rules.
    • Can search the store catalog.
    • Can ask the wallet to buy an item, up to 3 times per job.
    • Cannot set a price: prices come from the store.
    • Cannot change your rules, add funds, or approve its own request.
    • Cannot pay for the same item twice in one job.

    Your Claude key

    The agent uses Claude when you give it your own Anthropic API key. Without one, a simple keyword matcher stands in.

    The key stays in this browser tab. It is sent to this server with each agent run, used for that one request and never saved or logged. Only paste it into a copy you run yourself or trust.
